Stratora 2.4.3 is a security and integrity release. It corrects the bundled database version so every install — new or upgraded — runs the intended, current PostgreSQL 17.10.

<!-- truncate -->

## PostgreSQL 17.10, on every install

Stratora bundles PostgreSQL, and 2.4.3 ensures the version you actually run is the version we intend to ship: **PostgreSQL 17.10**, delivered correctly on both fresh installs and in-place upgrades.

In 2.4.2, a packaging defect meant installations ran the older **PostgreSQL 17.5** even though the release materials stated 17.10 — and this affected both fresh installs and in-place upgrades. 2.4.3 fixes the packaging so the intended 17.10 binaries are actually shipped and applied, and adds a build-time check that verifies the bundled database version so it can no longer silently drift.

**Why it matters.** PostgreSQL 17.6 through 17.10 carry upstream bug and security fixes. Systems on 2.4.2 were running the older 17.5. Upgrading to 2.4.3 brings the database current — and your software inventory or security scanner will report PostgreSQL 17.10 afterward.

**Your data is preserved.** The upgrade stops the database cleanly, replaces the binaries, and brings it back on 17.10 automatically — no manual steps, no data migration. Existing nodes, dashboards, and settings are retained.

## Upgrading

Download the 2.4.3 server installer and run it on your Stratora server. It is an in-place upgrade — existing data, dashboards, and settings are preserved, and 2.4.2 installs move to PostgreSQL 17.10 automatically as part of the upgrade.
